# Student Management System

A beginner-friendly **Student Management System built with Python** using Object-Oriented Programming (OOP), file handling, input validation, and basic data persistence.

## 📌 Features

* Add new students
* Display all students
* Search students by ID
* Update student information
* Delete students
* Course selection system
* Input validation
* Student data validation when loading from file
* Save student data to a text file
* Load saved student data automatically
* Clear all student data
* Delete the student data file
* Handles invalid or corrupted records while loading data

## 🛠️ Technologies Used

* Python
* Object-Oriented Programming (OOP)
* File Handling
* Exception Handling
* Input Validation
* Lists
* Getters and Setters

## 📂 Data Storage

Student records are stored locally in a `students.txt` file.

The system automatically loads valid saved records when the program starts and saves changes whenever student data is added, updated, or deleted.
